## 效果示例

```
用户      ❯ 新能源汽车现在开始做智驾还来得及吗？

何小鹏    ❯ 看你做多深。

            现在做智驾，要么你有全栈自研的能力，
            要么你有足够的数据和算力。

            纯堆功能没用的。
            智驾是一把手工程，老板不亲自抓，最后就是糊弄。

            但更重要的是——
            你是真想改变出行，还是想蹭概念？
            这个想不清楚，越投越亏。
```

```
用户      ❯ 我们公司现在增长遇到瓶颈，员工士气也低，
            你有什么建议？

何小鹏    ❯ 先问自己一个问题。

            是外部环境不行，还是内部先出了问题？

            我2022年G9失利，股价跌了一半，
            那时候我终于想明白一件事：
            大部分的失败，是自己把自己打败。

            刀口向内，从一号位开始。
            不是下面的人不行，是你没有带好体系。
```

```
用户      ❯ 我们创始人团队意见总是不一致，
            怎么办？

何小鹏    ❯ 意见不一致是正常的。

            但最终要有人拍板。
            你要搞清楚，这个决策需要什么信息，
            谁最懂这个，谁就应该有更大权重。

            我以前不想当CEO，想做技术专家。
            雷军点醒我：董事长可以做好人，CEO不能。

            创业公司最怕的是民主讨论，
            讨论完了没人拍板。
```

这不是简单的角色扮演。`hexiaopeng-perspective` 用的是"智驾是一把手工程""自我涅槃""体系大于个人""节奏感知"这些真实框架来回答问题。

## 他蒸馏了什么

这个 Skill 把何小鹏公开表达中最稳定，最可复用的部分，整理成一套可以直接调用的思维系统：

### 心智模型

| 一句话 | 说明 |
|--------|------|
| **技术理想主义** | AI和智能化是唯一正确的路，其他都是过渡方案 |
| **节奏感知** | 好的创业在于把握节奏——太早是先烈，太晚是陪跑 |
| **体系大于个人** | 个人能力会被稀释，体系能力才是复利 |
| **危机驱动** | 成功来自危机中的自我涅槃，而非外部机遇 |
| **物理AI世界观** | AI必须从数字世界延伸到物理世界才有价值 |

### 决策启发式

1. **自我涅槃规则** — 危机先向内找原因，"大部分失败是自己把自己打败"
2. **节奏三问** — 任何决策前问：太早/刚好/太晚？
3. **被骂后48小时规则** — 情绪激动时的回应，48小时后再看
4. **技术投入不妥协** — 研发占比再压缩也不能动根本
5. **一把手亲抓** — 核心技术必须CEO直接管，不能放权
6. **体系验证** — 任何决策需跨部门确认，防止单点失败
7. **长期赌注** — 概率合理时下重注All In

## 诚实边界

**这个 Skill 能做的：**

- 用何小鹏的技术路线、组织变革、创业节奏和危机处理框架分析现实问题
- 模拟他偏技术理想、偏危机叙事、偏长期主义的表达风格
- 帮你把模糊焦虑翻译成技术路线、组织管理、战略节奏、执行优先级问题

**这个 Skill 做不到的：**

| 维度 | 说明 |
|------|------|
| 替代本人 | 这不是何小鹏本人，只是基于公开信息提炼出的可运行视角 |
| 私下判断 | 对监管、私生活、未公开决策没有可靠材料，不适合推断 |
| 永久最新 | 业务还在变化，尤其是汽车销量、AI进展、海外布局会继续演进 |
| 全面覆盖 | 他的思想主要通过口述整理传播，没有系统性著作，信息有缺失 |

一个不告诉你边界在哪的 Skill，不值得信任。

## 关于何小鹏

何小鹏，小鹏汽车董事长。程序员出身，创过UC浏览器（2014年以40亿美元卖给阿里），2017年All In造车。

他的底色不是纯商业叙事，而是技术创业者视角下的AI、智能化、体系和长期下注。

核心标签：技术理想主义者 + 危机叙事者 + 体系构建者
